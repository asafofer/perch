Pick up goes straight to your agent in tmux and Warp

- An agent in a tmux pane opens in your tmux client, and a reply goes straight into its pane
- Claude Code installed with npm is found running, so Pick up in Warp goes to its tab instead of starting a second copy
- A session waiting on helpers or a command it left in the background stays at work until they report back
- A helper's own steps no longer clear the question the session is asking you
- A checkout with thousands of changes no longer leaves the list on "Looking for your sessions"
- A quick hello in a terminal stays in the list while its agent is open
