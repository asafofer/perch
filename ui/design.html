Avatar

Pick a shape. It updates the desktop above. Each row shows the four moods: asleep, awake, happy and peeking.

The glow is internal: light rising from the bottom edge of the card, tinted by status (orange needs you, green done, saffron otherwise). At rest the character is hidden. It pops out beside the notch with an orange dot only when something needs you.
